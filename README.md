# AudibleGraphics.com

The official website for **AudibleGraphics** - A website that generates narrated infographics.


## Tech Stack

This is a [Next.js](https://nextjs.org) project built with:
- **Next.js 15** with App Router
- **TypeScript**
- **Tailwind CSS v4**
- **Shadcn UI** components
- **Lucide React** icons
