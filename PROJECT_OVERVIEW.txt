AudibleSlides is a website that generates slideshows with images and narration for educational purposes.

Environment Variables:
NEXT_PUBLIC_SUPABASE_URL
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY
SUPABASE_SERVICE_ROLE_KEY
STRIPE_WEBHOOK_SECRET
STRIPE_SECRET_KEY
NEXT_STRIPE_PUBLISHABLE_KEY
NEXT_PUBLIC_STRIPE_PRO_PRICE_ID
NEXT_PUBLIC_STRIPE_ULTRA_PRICE_ID
DEEPGRAM_API_KEY
INWORLD_API_KEY
GEMINI_API_KEY
GEMINI_API_KEY2
OPENAI_API_KEY


Authentication
Supabase Email Auth with Row Level Security (RLS)

main_table:
- id - uuid (primary key, uuid_generate_v4())
- user_id - uuid (foreign key to auth.users.id)
- created_at - timestamptz (default now())
- stripe_customer_id - text
- stripe_subscription_id - text
- pro_end_date - timestamptz
- pro_start_date - timestamptz
- cancel_at_period_end - boolean (default false)
- subscription_tier - text (Null, Pro, Ultra)
- monthly_generated_slideshows - int2 (How many slides the user has generated this month)
- last_reset_date - timestampz (default now(), when the monthly_generated_slides was last reset)

presentations:
- id - uuid (primary key, uuid_generate_v4())
- user_id - uuid (foreign key to profiles.user_id, CASCADE delete)
- title - text
- created_at - timestamptz (default now())
- image_url - text
- audio_url - text
- speaker_notes - text

Storage Buckets

slide-images
- Private bucket (10MB limit)
- Allowed types: image/png, image/jpeg, image/jpg, image/webp
- Path structure: `{user_id}/{presentation_id}/{slide_id}.png`

slide-audio
- Private bucket (50MB limit)
- Allowed types: audio/mpeg, audio/mp3, audio/wav
- Path structure: `{user_id}/{presentation_id}/{slide_id}.mp3`

RLS policies enforce users only access files in folders matching their user_id.
